SpeakEasy Mini - Third-Party Notices
=====================================

Artifact status
---------------
This notice accompanies an unsigned Windows artifact that is publicly
distributed, as SpeakEasyMiniSetup.exe on the project's GitHub Releases page.
It is not code-signed and may trigger Windows SmartScreen. The exact Rust and
npm dependency versions are recorded in Cargo.lock and package-lock.json.

Two things are distributed and they are not the same set. What the installer
carries is listed under "Embedded in the installer" below; what setup fetches
over the network after the user chooses a configuration is listed under
"Downloaded by setup". Everything in the second list is verified by SHA-256
against models/trusted-manifest.json before it is installed.

Embedded in the installer
-------------------------
The payload appended to SpeakEasyMiniSetup.exe is three executables --
speakeasy-bootstrapper.exe, ai-speakeasy-mini.exe and granite-worker.exe --
with no native library beside them.

No third-party native runtime is embedded. This section declared sherpa-onnx,
ONNX Runtime and the NVIDIA CUDA redistributables until 2026-08-18; all three
left with the streaming engine. llama.cpp is compiled directly into
granite-worker.exe and is covered below.

The embedded granite-worker.exe is a CPU build: Invoke-ProofPackage.ps1 builds
the worker with default features, which do not include CUDA. A graphics-card
installation downloads a CUDA build of the same source instead, and setup stages
it over this one -- see below.

Downloaded by setup
-------------------
None of the following is embedded in SpeakEasyMiniSetup.exe. Each is fetched
after the user has chosen a configuration, from the URL pinned in
models/trusted-manifest.json, and is verified by SHA-256 against that file
before it is installed. The manifest records the licenses each entry is
published under; it is the authoritative record and this list summarises it.

A fresh install downloads, as does any install that does not already have a
verified copy of the model on disk:

  Granite Speech 4.1 2B weights (two GGUF files, 2.30 GB)
  License: Apache-2.0, IBM Corporation
  Host: Hugging Face, pinned at an immutable commit
  See MODEL-NOTICES.md.

A user who chooses the graphics-card configuration additionally downloads:

  granite-worker-cuda-windows-x64.zip (42.2 MB, one granite-worker.exe of
  57,052,672 bytes)
  Host: Hugging Face, huggingface.co/orangeblue39/speakeasy-mini-runtime,
  pinned at an immutable commit.
  This archive is built and published by this project from the same llama.cpp
  and llama-cpp-rs sources declared above, with CUDA enabled. It therefore
  carries the MIT terms of llama.cpp/ggml and of the vendored C/C++ libraries
  listed above, and it statically links the NVIDIA CUDA runtime, which is
  distributed under the NVIDIA CUDA Toolkit EULA. That repository carries its
  own NOTICE.md reproducing the MIT texts and naming the EULA. Unlike the two
  NVIDIA archives below, these are bytes this project redistributes.

  cuda_cudart-windows-x86_64-13.3.29-archive.zip (2.6 MB)
  libcublas-windows-x86_64-13.6.0.2-archive.zip (393.7 MB)
  License: NVIDIA CUDA Toolkit EULA
  Host: NVIDIA's own redistributable CDN, developer.download.nvidia.com.
  These are fetched directly from NVIDIA by the user's machine and are not
  redistributed by this project or contained in any artifact it publishes.
