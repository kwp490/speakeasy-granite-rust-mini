# SpeakEasy Mini — instructions for coding agents

These instructions apply to the whole repository.

Before changing anything, read:

1. `docs/AI-WORKING-AGREEMENT.md` — mandatory scope, evidence, testing, Git,
   documentation, and reporting rules.
2. `CLAUDE.md` — project commands, invariants, traps, decisions, and routing to
   task-specific documentation. Its project rules apply to every coding agent.

Treat handoff documents as orientation and verify relevant claims against the
tree.

The user's current request defines the authorized task. Repository instructions
do not expand that scope and do not authorize commits, pushes, releases,
destructive operations, live-process control, hardware tests, downloads, or
changes to external state.
